## الهدف
جعل تسجيل الدخول اختياري تماماً. الزبون يقدر يتصفح، يضيف للسلة، ويكمل الطلب بدون حساب — بس يدخل معلومات التوصيل (الاسم، الهاتف، المحافظة+المنطقة). إذا سجل دخول، يحصل على مميزات إضافية (مفضلة، سجل طلبات، نقاط).

## المبدأ العام
لن ألمس أي ملف أو ميزة موجودة إلا للضرورة القصوى. الميزة الجديدة (Guest Checkout) ستُبنى بملفات مستقلة، ومسار جديد للطلب بدون حساب.

## التغييرات

### 1. سلة الضيف (localStorage)
- ملف جديد: `src/lib/guest-cart.ts` — إدارة سلة في localStorage للزوار.
- تعديل صغير في `src/routes/_authenticated/cart.tsx` → نقله إلى `src/routes/cart.tsx` (route عام) يعرض:
  - إذا مسجل: يستخدم `cart_items` من DB (نفس المنطق الحالي).
  - إذا ضيف: يستخدم localStorage.
- أزرار "إضافة للسلة" في المنتجات لا تحتاج تعديل جوهري — تستدعي helper يقرر تلقائياً حسب حالة الدخول.

### 2. صفحة الدفع للضيف
- ملف جديد: `src/routes/checkout.tsx` (route عام):
  - إذا مسجل: يعيد التوجيه للصفحة الحالية `_authenticated/checkout`.
  - إذا ضيف: يعرض فورم مبسط (اسم كامل، هاتف، محافظة، منطقة، أقرب نقطة دالة اختياري، ملاحظة) + طريقة الدفع + ملخص السلة.

### 3. دالة قاعدة بيانات جديدة (بدون auth)
- migration جديد: `place_guest_order(p_items jsonb, p_address jsonb, p_payment text, p_notes text)`:
  - لا تتطلب `auth.uid()`.
  - تتحقق من المخزون وتخصمه.
  - تنشئ طلب بـ `user_id = NULL` في جدول `orders`.
  - ترجع `order_id` + `order_number`.
- تعديل جدول `orders`: جعل `user_id` nullable (إذا مو nullable حالياً).
- تعديل جدول `orders` RLS: إضافة سياسة اختيارية للضيف بحيث يقدر يقرأ طلبه فقط عبر `order_number` (أو نستخدم صفحة تتبع بالرابط المباشر).

### 4. صفحة تأكيد ومتابعة الطلب للضيف
- المسار الحالي `order-success.$id.tsx` أصلاً عام — سنعرض فيه الطلب سواء ضيف أو مسجل.
- إضافة صفحة تتبع مستقلة `src/routes/track.tsx` يدخل فيها الضيف رقم الطلب + الهاتف لرؤية حالة طلبه (بدون حساب).

### 5. صفحة `/auth` — تبقى كما هي
- لا نلغيها. تصير اختيارية فقط.
- نضيف في الهيدر/القائمة زر "تسجيل دخول للحصول على النقاط والمفضلة" — بدون إجبار.

## تفاصيل تقنية

**الملفات الجديدة:**
- `src/lib/guest-cart.ts`
- `src/lib/guest-order.functions.ts`
- `src/routes/cart.tsx` (بديل عام لـ `_authenticated/cart.tsx` القديم — نبقيه للمسجلين)
- `src/routes/checkout.tsx` (بديل عام لـ `_authenticated/checkout.tsx`)
- `src/routes/track.tsx`

**الملفات المُعدّلة (بأقل قدر ممكن):**
- `src/components/bottom-nav.tsx` / `src/components/app-header.tsx` — تعديل روابط السلة/الدفع فقط لتشير للمسار العام.
- إضافة migration واحد لجعل `orders.user_id` nullable + دالة `place_guest_order` + سياسات RLS.

**ما لن يُلمس:**
- `_authenticated/*` كاملاً يبقى شغال للمسجلين.
- `place_order` RPC الحالي.
- تصميم أي صفحة موجودة.
- منطق النقاط، المفضلة، الاستبدال، الإشعارات، الأدمن.

## المخاطر
- تعديل `orders.user_id` ليصير nullable قد يؤثر على استعلامات الأدمن — سأتحقق من لوحة الأدمن قبل التنفيذ.
- إضافة route جديد `/cart` و`/checkout` قد يتعارض مع الروابط الحالية — سأتأكد أن `_authenticated/cart` و`_authenticated/checkout` لا يزالان يعملان للمسجلين، أو نوحّد على المسار العام مع منطق داخلي.
